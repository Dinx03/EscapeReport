และไฟล์เสียง 4 ไฟล์"* ซึ่งเดิมระบุว่า "ไม่มีข้อมูลในโปรเจกต์"

`LICENSE`, `README`, `CREDITS` หรือ `ATTRIBUTION` ใด ๆ (ไฟล์ `.txt` ไฟล์เดียวใน
โปรเจกต์คือ `ProjectSettings/ProjectVersion.txt`)

> ⚠️ **ต้องให้ผู้เขียนยืนยันก่อนเขียนลงรายงาน**
> ถ้าดาวน์โหลดมาจาก kenney.nl จริง ให้อ้าง CC0 ได้และควรใส่เครดิตแม้ CC0 ไม่บังคับ
> ถ้าดาวน์โหลดจาก Unity Asset Store หรือที่อื่น **สัญญาอนุญาตเป็นอย่างอื่นและต้องอ้างตามนั้น**

อ่านส่วนหัวและส่วนท้ายของทั้งสี่ไฟล์เพื่อหา ID3 tag

| ฟิลด์ที่มองหา | ผล |

| URL แหล่งที่มา (WXXX / WOAF) | **ไม่พบ** |
| คอมเมนต์ (COMM) | **ไม่พบ** |
| โปรแกรมเข้ารหัส | พบ `LAME3.100` ใน `clock-bg.mp3` และ `clock-cuckoo.mp3` |

**ทั้งสี่ไฟล์ไม่มี ID3 tag ใด ๆ เลย** จึงสรุปได้เพียงว่า
- ถูกเข้ารหัสด้วย LAME เวอร์ชัน 3.100 (อย่างน้อยสองไฟล์) ซึ่งเป็นตัวเข้ารหัสที่
  เว็บคลังเสียงฟรีและโปรแกรมแปลงไฟล์ทั่วไปใช้
- ชื่อไฟล์เป็นแบบ `kebab-case` ทั้งหมด ซึ่งเป็นรูปแบบชื่อที่เว็บดาวน์โหลดเสียงตั้งให้
- **ไม่มีหลักฐานใดในโปรเจกต์ที่บอกแหล่งที่มาหรือสัญญาอนุญาตได้**

> ⚠️ **ข้อนี้ต้องมาจากผู้เขียนเท่านั้น และ "เดาแทนไม่ได้"**
> นี่คือข้อมูลชิ้นเดียวในรายงานทั้งเล่มที่ไม่มีทางหาจากไฟล์ได้
> และเป็นข้อที่อาจารย์ตรวจได้ง่ายที่สุดด้วย เพราะเสียงที่ใช้ในงานต้องบอกที่มา
>
> **สิ่งที่ต้องทำ** เปิดประวัติการดาวน์โหลดของเบราว์เซอร์ ย้อนไปวันที่
> **7 กันยายน 2569 เวลาประมาณ 12:10–12:13 และ 16:39** จะได้ URL ต้นทางของทั้งสี่ไฟล์พอดี
> (สามไฟล์แรกดาวน์โหลดห่างกันไม่ถึงสามนาที จึงอยู่ติดกันในประวัติแน่นอน)

**ฟอนต์นี้ถูกคัดลอกเข้ามาเก็บในโปรเจกต์จริง ไม่ใช่การเรียกใช้ฟอนต์ของระบบ**

`AssetDatabase.LoadAssetAtPath<Font>("Assets/Fonts/LeelawadeeUI.ttf")`

### 4.2 ⚠️ ข้อที่ควรระบุในรายงานอย่างตรงไปตรงมา

Leelawadee UI เป็นฟอนต์ที่ **Microsoft แจกมาพร้อม Windows** ไม่ใช่ฟอนต์เสรี
สัญญาอนุญาตของฟอนต์ที่มาพร้อม Windows อนุญาตให้ *ใช้* บนเครื่องที่มีสิทธิ์ Windows
แต่โดยทั่วไป **ไม่อนุญาตให้แจกต่อ (redistribute) ไปพร้อมกับซอฟต์แวร์ของเราเอง**
การคัดลอก `.ttf` เข้าไปใน `Assets/` แล้ว build เกมออกไปคือการแจกต่อ

**นี่เป็นประเด็นที่อาจารย์ตรวจพบได้ง่าย** เพราะชื่อฟอนต์อยู่ในชื่อไฟล์ตรง ๆ

แนวทางที่ตรงที่สุดสามทาง เลือกหนึ่ง
1. **ระบุไว้ในข้อจำกัดของโครงงาน** ว่าใช้ฟอนต์ระบบของ Windows ระหว่างพัฒนา
   และการเผยแพร่จริงต้องเปลี่ยนไปใช้ฟอนต์ที่มีสัญญาอนุญาตให้แจกต่อได้ ← **แนะนำข้อนี้**
   เพราะเป็นเรื่องจริง ตรวจสอบได้ และแสดงว่าผู้เขียนรู้เรื่องสัญญาอนุญาต
2. เปลี่ยนไปใช้ฟอนต์ไทยที่เป็น SIL Open Font License เช่น Sarabun หรือ Noto Sans Thai
   แล้วรายงานว่าเปลี่ยนแล้ว — แต่ต้องแก้โปรเจกต์ ซึ่งอยู่นอกขอบเขต read-only ของรอบนี้
3. ไม่พูดถึงเลย — **ไม่แนะนำ** เพราะถ้าอาจารย์ถาม จะกลายเป็นข้อที่ตอบไม่ได้
