## รูปเล่ม Word

`รายงานสหกิจศึกษา-EscapeRoom-ร่าง.docx` — **124 หน้า** จัดตามข้อกำหนดใน
`report/exam_report/รูปเล่มสหกิจสำหรับคณะวิศวะ.pdf` แล้วทั้งหมด

| รายการ | สถานะ |
|---|---|
| ขอบกระดาษ บน-ซ้าย 1.5 นิ้ว ล่าง-ขวา 1 นิ้ว | ตั้งแล้ว ตรวจจาก PDF ที่ส่งออกแล้ว |
| TH Sarabun New ทั้งเล่ม รวมเลขหน้า | ตรวจแล้วทุกหน้า ยกเว้นสัญลักษณ์ 📸 ⚠️ ในกล่องที่ต้องลบ และลูกศร → ในตารางหนึ่งตาราง |
| ชื่อบทหนา 20 · x.x หนา 18 · x.x.x หนา 16 · เนื้อความ 16 | วัดจาก PDF ได้ตรงกับหน้าตัวอย่างของแบบฟอร์มทุกพิกัด |
| เลขหน้ามุมขวาบน · ส่วนหน้า ก–ฌ · เนื้อหา 1–111 | ถูก และหน้าแรกของทั้งห้าบทไม่แสดงเลขหน้า |
| บทสรุปและ Summary ไม่เกิน 1 หน้า | พอดีหน้าเดียวทั้งคู่ |
| สารบัญ · สารบัญตาราง · สารบัญรูป | Word สร้างให้แล้ว 32 + 40 + 29 รายการ พร้อมเลขหน้าจริง |
| คำบรรยายตารางอยู่บน ชิดซ้าย · คำบรรยายรูปอยู่ใต้รูป | ถูกทั้ง 40 ตารางและ 29 รูป |
| เอกสารอ้างอิง IEEE [1]–[29] | รวมไว้ท้ายเล่มชุดเดียว |

**สิ่งที่ต้องทำเองในไฟล์ Word** เขียนไว้ครบในหน้าแรกของไฟล์
(หน้านั้นชื่อ *หน้านี้ไม่ใช่ส่วนของรายงาน — ลบทิ้งก่อนส่ง*) สรุปคือ
ลบกล่องพื้นเหลือง 38 กล่อง · แทนกรอบเส้นประ 27 กรอบด้วยรูปจริง ·
เติมช่อง `[...]` ในปก หน้าอนุมัติ ประวัติผู้จัดทำ · พิมพ์หัว "(ต่อ)" ให้สารบัญหน้าถัดไป

### ถ้าแก้ไฟล์ใน `md/` แล้วอยากสร้างรูปเล่มใหม่

```
py tools\md2docx.py
powershell -File tools\finish-docx.ps1
```

คำสั่งแรกสร้าง `.docx` ใหม่จากไฟล์ใน `md/` **ทับของเดิม** คำสั่งที่สองสั่ง Word
อัปเดตสารบัญกับเลขหน้าแล้วส่งออก PDF ด้วย

⚠️ **อย่าแก้เนื้อหาใน Word แล้วสร้างใหม่** เพราะจะถูกทับ — ถ้าจะแก้เนื้อหา
ให้แก้ที่ไฟล์ `md/` หรือเลิกใช้สคริปต์แล้วแก้ใน Word อย่างเดียวไปเลย
ตอนจัดรูปเล่มขั้นสุดท้าย (ลบกล่อง วางรูป) ให้ทำใน Word และไม่ต้องสร้างใหม่อีก

ถ้าเครื่องใหม่ไม่มี Python ให้ติดตั้ง Python แล้ว `py -m pip install python-docx`
ส่วน `finish-docx.ps1` ต้องมี Microsoft Word ติดตั้งอยู่ ถ้าไม่มีก็เปิด `.docx`
แล้วกด Ctrl+A ตามด้วย F9 เอง ได้ผลเหมือนกัน

   และสถานะที่หลักฐานบันทึกไว้คือ **698 ไฟล์ใน `Assets/` · ใหม่สุด 8 ก.ย. 2569 09:46**
   ถ้าโปรเจกต์เปลี่ยน หลักฐานในรายงานจะไม่ตรงกับไฟล์จริง
2. **ทุกประโยคต้องมีหลักฐาน** ชี้ `ไฟล์:บรรทัด` หรือระบุว่าเป็นข้อมูลจากผู้เขียน
3. **อ้างจากซอร์สโค้ดและฉากจริง ไม่ใช่จาก `CLAUDE.md`** — เอกสารในโปรเจกต์ทั้งสามฉบับ
   นับไม่ตรงกับไฟล์จริงหลายจุด (เช่น 47 นาฬิกา → จริง 46 · 28 implementation → จริง 29)
   ใช้เอกสารได้เฉพาะเรื่อง **เจตนาและเหตุผล** ซึ่งเป็นสิ่งที่โค้ดบอกไม่ได้
4. **ไม่มีข้อมูล = เขียนว่าไม่มี ไม่ใช่แต่ง** โดยเฉพาะที่มาของไฟล์เสียง
   การเขียนว่า "ไม่ได้บันทึกแหล่งที่มาไว้ ซึ่งเป็นข้อบกพร่องด้านการจัดการสินทรัพย์"
   ดีกว่าการเดาชื่อเว็บมาก
