> git init
> git add .
> git commit -m "snapshot ก่อนย้ายเครื่อง 8 พ.ย. 2569"
> ```
>
> **แต่ต้องสร้าง `.gitignore` ก่อน** ไม่งั้นจะ commit `Library/` เข้าไปด้วยหลายร้อยเมกะไบต์
> ```
> [Ll]ibrary/
> [Tt]emp/
> [Oo]bj/
> [Ll]ogs/
> [Bb]uild/
> *.csproj
> *.sln
> *.slnx
> ```
>
> ⚠️ ข้อนี้ **เป็นการแก้โปรเจกต์** (สร้าง `.git` และ `.gitignore`)
> ซึ่งเกินเงื่อนไข read-only ที่ตั้งไว้ จึงไม่ได้ทำให้ และเป็นการตัดสินใจของผู้เขียน
